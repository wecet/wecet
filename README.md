I'm Owen, an AI Engineer at [AIVHY](https://aivhy.com), specialising in computer vision. At work I've built industrial image classification, anomaly detection and object detection systems; deployed with Docker on Edge Devices. I also care as much about how something looks as how it works, so most of my side projects end up with more time spent on the UI than I'd like to admit.

### 🍊 [tangerine](https://github.com/wecet/tangerine)

A native macOS app that gives your Desktop and Finder files a few extra tricks. Option-click a file for a citrus wheel of conversions, or Shift-click for utilities like crop, AirDrop and rename.
<br><sub>Swift · AppKit · Vision · Docker</sub>
